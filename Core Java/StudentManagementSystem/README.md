# Student Management System

Core Java console application for managing student details.

## Features

- Add a student
- Display all students
- Search by student ID
- Search by name
- Update marks
- Update attendance
- Calculate grade
- Remove a student
- Display topper
- Save student details to a file
- Load student details from a file

## Core Java Concepts

- Classes and Objects
- Encapsulation
- HashMap
- ArrayList
- Enum
- Exception Handling
- File Handling
- Methods
- Loops
- Conditional Statements
