# Inventory Management System

Core Java console application for a small electronics shop.

## Features
- Add product
- Search by ID
- Update price
- Add stock
- Sell product
- Show all products
- Show products with stock below 5
- Calculate bill
- Delete product
- Save/load product data

## Concepts
OOP, Encapsulation, HashMap, ArrayList, Enum, Exception Handling, File Handling.
